# Task 1 - Superstore Retail Sales Exploratory Data Analysis

## Overview

This project performs exploratory data analysis on the Superstore retail sales dataset to identify sales patterns, profitability trends, customer segments, regional performance, and the impact of discounts.

## Contents

- `Data/superstore_sales.csv` - Source sales dataset.
- `Notebook/Superstore_Retail_Sales_EDA.ipynb` - Main EDA notebook.
- `Notebook/README_Superstore_EDA.md` - Notebook-specific documentation.
- `Screenshot 2026-11-10 170240.png` - Analysis screenshot.

## Analysis

The notebook includes:

- Data quality and missing-value checks
- Sales and profit KPIs
- Customer segment analysis
- Monthly sales seasonality
- Category and sub-category performance
- Regional performance
- Discount versus profit analysis
- Executive findings and recommendations

## Requirements

Install the required Python packages:

```bash
python -m pip install pandas numpy matplotlib seaborn jupyter
```

## Run the Project

1. Open a terminal in this project directory.
2. Start Jupyter Notebook:

```bash
jupyter notebook
```

3. Open `Notebook/Superstore_Retail_Sales_EDA.ipynb`.
4. Run all cells using **Kernel > Restart & Run All**.

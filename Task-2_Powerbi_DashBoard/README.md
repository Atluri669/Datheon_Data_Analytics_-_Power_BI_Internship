# Task 2 - Superstore Sales and Profit Dashboard

## Overview

This project analyzes the Superstore sales dataset and presents key sales, profit, customer, category, and regional insights in an interactive Power BI dashboard.

## Contents

- `Data/superstore_sales.csv` - Source sales dataset.
- `NoteBook/Superstore_Analysis.ipynb` - Notebook used for data preparation and analysis.
- `Dashboard/Superstore_Executive_Sales_Profit_Dashboard.pbix` - Power BI dashboard.
- `Screenshot 2026-11-10 170343.png` - Dashboard preview.

## Dashboard Features

- Executive sales and profit KPIs
- Category and sub-category performance
- Regional sales and profit analysis
- Customer and segment comparisons
- Monthly sales and profit trends
- Interactive filters and drill-down views

## Requirements

- Microsoft Power BI Desktop
- Python, Jupyter, and the following packages for notebook work:

```bash
python -m pip install pandas numpy matplotlib seaborn jupyter
```

## How to Use

1. Open `Dashboard/Superstore_Executive_Sales_Profit_Dashboard.pbix` in Microsoft Power BI Desktop.
2. Use the dashboard slicers and filters to explore the data.
3. To review or reproduce the analysis, open `NoteBook/Superstore_Analysis.ipynb` in Jupyter Notebook.

# Task 4 - Financial Analysis Dashboard

## Overview

This project uses the Financial Sample dataset to analyze revenue, profit, cost, sales performance, and business trends through an interactive Power BI dashboard.

## Contents

- `Data/financial_sample.xlsx` - Source financial dataset.
- `Visulaization/Financial Analysis.pbix` - Power BI financial analysis dashboard.
- `abstract-wireframe-technology-background-presentation-banner-cover_654662-5665.avif` - Project image asset.
- `green-futuristic-waves-background-vector-with-computer-code-technology_53876-110868.avif` - Project image asset.

## Dashboard Features

- Sales and revenue overview
- Profit and cost analysis
- Product and segment performance
- Country or region analysis
- Time-based financial trends
- Interactive filters and drill-down views

## Requirements

- Microsoft Excel for viewing the source dataset
- Microsoft Power BI Desktop for opening and editing the dashboard

## How to Use

1. Open `Data/financial_sample.xlsx` to review the source data.
2. Open `Visulaization/Financial Analysis.pbix` in Microsoft Power BI Desktop.
3. Use the dashboard filters and visual interactions to explore financial performance.
